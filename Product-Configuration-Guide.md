# Product Configuration Guide

## Configure a service profile

Use this procedure to create a service profile and assign the required configuration values.

### Prerequisites

Before starting:

- Ensure that the required administrator permissions are available.
- Confirm the service is deployed and operational.
- Obtain the values required for the service profile.

### Procedure

1. Open **Administration > Service Profiles**.
2. Select **Create profile**.
3. Enter a unique name for the profile.
4. Select the required service type.
5. Enter the configuration values.
6. Select **Validate**.
7. Review the validation results.
8. Select **Save**.

### Validation

The system validates mandatory fields and supported values before saving the profile.

If validation fails, correct the reported values and run validation again.

### Result

The new service profile is created and appears in the **Service Profiles** list with an **Active** status.
